Introduction to Javascript

JavaScript ― это интерпретируемый язык программирования общего назначения с динамической типизацией данных.

Интерпретируемый значит, что программа выполняется в исходном виде, т.е. исходный код не преобразуется в машинный или промежуточный код. В связи с этим, ошибок на этапе компиляции и компоновки отсутствуют, есть только ошибки на этапе выполнения.

Динамическая типизация говорит о том, что тип переменных и констант определяется во время присваивания по типу значения справа (r-value)
l-value = r-value.

Переменные и типы данных

Переменные и константы

var
Объявляет глобальную переменную, несмотря на область видимости, в которой она объявлена. Если записать значение в несуществующую переменную, то это не вызовет ошибку, это будет аналогично ключевому слову ‘var’
let
Объявляет локальную переменную только для той области видимости, в которой она используется
const
Объявляет константу. Константы могут быть только локальными.

Типы данных

  1. Примитивные типы:
    • Boolean ― принимает одно из двух значений True либо False. Значения: 0, null, ‘’, “”, `` неявно преобразуются в False. True ― это любое значение, отличное от нуля и пустой строки.
    • String ― объект, описывающий массив символов.
    • Number ― вещественное (дробное) число, которое является полным аналогом типа double. Все числовые литералы неявно преобразуются в Number.
