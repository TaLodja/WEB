Дескрипторы физического форматирования

В HTML все делается через дескрипторы.

<p> (Paragraph) ― этот дескриптор описывает абзац;
<br> (Break) ― этот дескриптор, расположенный в конце строки кода, переносит текст на новый абзац;
<b> (Bold) ― этот дескриптор делает шрифт жирным;
<i> (Italic) ― этот дескриптор делает шрифт курсивным;
<u> (Underline) ― этот дескриптор делает шрифт подчеркнутым;
<s> (Strikeout) ― этот дескриптор делает шрифт перечеркнутым;
<tt> (Teletype text) ― этот дескриптор делает шрифт моноширным или монохромным (DEPRECATED);
<sub> (Subscript) ― нижний индекс;
<sup> (Superscript) ― верхний индекс;
Дескрипторы логического форматирования

Дескрипторы логического форматирования нужны для анализа страницы поисковыми машинами. Многие из них замещают дескрипторы физического форматирвания

<strong> (Bold) ― этот дескриптор делает шрифт жирным;
<em> (Emphasis) ― этот дескриптор делает шрифт курсивным;
<del> (Delete - Strikeout) ― этот дескриптор делает шрифт перечеркнутым;
<code> (Code) ― этот дескриптор делает шрифт моноширным;
<mark> (Mark) ― этот дескриптор делает шрифт выделенным;
<cite> (Citation) ― так обозначают цитаты;
